# CivicPulse

### Smart City Urban Incident & Complaint Analytics Dashboard

CivicPulse is an interactive smart city dashboard designed to help municipal authorities monitor, prioritize, and analyze urban incidents and citizen complaints.

The project was developed as an **assignment for my IPE (Innovation and Product Engineering) classes**, with a focus on applying modern frontend development, data visualization, and AI-assisted product design concepts.

## Features

- **Incident Management:** Filter and prioritize incidents by department, ward, severity, and status.
- **Ward Analytics:** Analyze incident volumes, SLA performance, resolution times, and ward-level efficiency.
- **Dispatch Console:** Simulated fleet tracking, crew assignment, GPS telemetry, and CAD-style dispatch workflows.
- **Data Visualization:** Interactive SVG charts, performance matrices, heatmaps, and KPI dashboards.
- **Prompt Engineering Workspace:** Structured AI prompts, JSON schemas, prompt comparisons, and testing scenarios.
- **Dynamic State Updates:** Dashboard metrics, charts, and tables update based on user interactions.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Lucide React
- Material Symbols
- SVG Data Visualization
- Web Audio API

## Key Highlights

- Responsive command-center style interface
- Realistic simulated municipal data covering **12 wards and 5 departments**
- Simulated fleet telemetry for **42 field units**
- SLA and incident analytics
- Interactive dispatch and incident workflows
- Institutional civic design system with custom design tokens

## Disclaimer

CivicPulse is a **frontend prototype using simulated data**. The incidents, telemetry, departments, wards, and operational metrics do not represent real municipal systems.
